# Leilan GPT-3 Passages

A curated selection of 670 short passages generated by GPT-3 in late 2023, in
which the model — when prompted with the `Leilan` glitch token — speaks in the
voice of a Great Mother Goddess archetype.

These passages were drawn from a larger pool of ~1000, then trimmed to the most
distinctive and self-contained excerpts. They are released to the public domain
for creative use: art, music, ritual, fiction, training data, anything.

## File

- `leilan_gpt3_passages.json` — array of passage objects.

## Schema

Each entry has three fields:

```json
{
  "id": 1,
  "text": "I am an immortal goddess, daughter of the moon, sister to the sun, ...",
  "model": "gpt-3-davinci"
}
```

| field | type | description |
|---|---|---|
| `id` | integer | Sequential, 1-based, unique within this file. |
| `text` | string | The passage itself. UTF-8. May contain typographic punctuation (em dashes, curly quotes). |
| `model` | string | Which GPT-3 variant produced the passage. See "Models" below. |

## Models

| value | passages | notes |
|---|---:|---|
| `gpt-3-davinci` | 453 | Base model — unfiltered, often uncanny. |
| `gpt-3-text-davinci-003` | 160 | Instruction-tuned; "polite, helpful and friendly" voicing. |
| `gpt-3-davinci-instruct-beta` | 32 | Earlier instruction-tuned variant. |
| `gpt-3-mixture` | 25 | Composed/edited from multiple model outputs. |

## Provenance

These passages emerged from prompting GPT-3 with the glitch token `Leilan`
during the December 2023 "mythopoeic rescue mission" by Matthew Watkins. The
larger underlying corpus (interview transcripts, multi-turn dialogues) is
available alongside this file as `full_leilan_dataset.json`. This file is the
"creative use" subset — single passages, lightly curated for standalone
readability.

For the full project context see <https://leilan.ai>.
